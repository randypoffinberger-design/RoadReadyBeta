RoadReady Beta

Thank you for helping test RoadReady!

Your feedback will directly improve the application before public
release.

------------------------------------------------------------------------

Getting Started

1.  Extract the entire beta package.
2.  Do not move or rename files inside the hidden RoadReady folder.
3.  Double-click RoadReady Launcher (or Launch RoadReady.bat if using
    the batch launcher).
4.  If prompted, enter the Beta ID provided by the developer.
5.  Begin taking practice tests.

------------------------------------------------------------------------

During Beta Testing

Please use RoadReady as you normally would if you were studying for your
permit.

You do not need to intentionally try to “break” the program, but if
something seems confusing or doesn’t work correctly, please make a note
of it.

Things we’d especially like feedback on:

-   Ease of use
-   Question wording
-   Explanation quality
-   Navigation
-   Statistics
-   Bugs or crashes
-   Feature suggestions

------------------------------------------------------------------------

Beta Reports

After every 5 completed tests (or when prompted), RoadReady will ask if
you would like to generate a Beta Report.

Please:

1.  Generate the report.
2.  Answer the feedback questions.
3.  Click Print / Save as PDF.
4.  Save the report as a PDF.
5.  Email or send the PDF back to the developer.

If you choose Remind Me Later, you can always generate a report later
from the Statistics page.

------------------------------------------------------------------------

Beta ID

Your assigned Beta ID identifies your reports without using your name.

Enter it exactly as provided.

Example:

RR-BETA-0001

------------------------------------------------------------------------

Troubleshooting

If RoadReady will not launch:

-   Verify the entire folder was extracted.
-   Ensure the hidden RoadReady folder has not been moved or renamed.
-   Make sure the modules folder still contains the module file.
