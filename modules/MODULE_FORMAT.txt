ROADREADY PHASE TWO MODULE FORMAT

A module may declare these capabilities:

"capabilities": {
  "practiceTests": true,
  "study": true,
  "flashcards": true,
  "images": true,
  "lessons": true,
  "chapterQuizzes": true,
  "reference": true,
  "search": true
}

RoadReady only shows a feature when the module contains the required content. Older question-bank modules continue to support tests, Study Mode, and Flashcards automatically.

LESSONS
Add a top-level lessons array:

"lessons": [
  {
    "id": "lesson-1",
    "chapter": "Chapter 1",
    "title": "Introduction",
    "summary": "Shown on the lesson list.",
    "content": "Full lesson text. Blank lines create paragraphs.",
    "image": "modules/images/example.png",
    "quizQuestionIds": ["SAMPLE-001", "SAMPLE-002"],
    "passingScore": 2
  }
]

A lesson can use either content or sections:

"sections": [
  {"heading":"Topic One", "content":"Text for this topic."},
  {"heading":"Topic Two", "content":"Text for this topic."}
]

LESSON QUIZZES
The easiest method is quizQuestionIds, which reuses questions from questionBank. A lesson can instead contain its own quiz array using the same question/choices/explanation structure as questionBank.

REFERENCE LIBRARY
Add a top-level referenceLibrary array:

"referenceLibrary": [
  {
    "id": "ref-1",
    "category": "Vocabulary",
    "title": "Example Term",
    "summary": "Short list description.",
    "content": "Full searchable reference text.",
    "tags": ["term", "definition"],
    "image": "modules/images/example.png",
    "source": "Optional source citation"
  }
]

SEARCH
Search works automatically across lesson titles and text, reference entries and tags, and all study questions and explanations. Set search to false only when the module should not expose search.

MODULE REMOVAL
Downloaded and locally imported modules can be removed from the Module Library. The built-in starter module cannot be removed. Removing a module keeps its statistics and lesson progress so they return if the same module is installed again.

IMAGES
Question, answer-choice, lesson, and reference images may use a relative URL, HTTPS URL, or data:image URL. Locally imported JSON cannot carry separate image files by itself, so use hosted URLs, data:image values, or publish the module and image folder together on GitHub.

ONLINE CATALOG
Add optional modules to modules/catalog.json with bundled set to false. They are downloaded only after the user taps Download Module.

See module-template.json for a working Phase Two example.
